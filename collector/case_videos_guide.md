# case_videos.csv 작성 안내

- 위치: `project3/collector/case_videos.csv`
- 1줄 = 영상 1개. 사례 하나에 영상이 여러 개면 같은 `case_id`로 줄을 추가 (사례당 최대 3개)
- 대상: `cases.csv`에서 `status`가 **후보**인 사례만

## 직접 채우는 칸 (3개)

| 열 | 넣을 값 | 예시 |
|---|---|---|
| `video_url` | 유튜브 주소 전체 (일반·짧은 주소·쇼츠 모두 가능) | `https://www.youtube.com/watch?v=abcdEFGhijk` |
| `video_kind` | `브랜드 공식` 또는 `뉴스 리포트` 중 하나 | `브랜드 공식` |
| `note` | 판단 근거, 특이사항 | `대행사(대홍기획) 채널`, `설명란에 'AI로 제작' 표기 있음` |

## 자동으로 채워지는 칸 (비워 두기)

`title`, `channel`, `published_at`, `video_exists`, `comments_enabled`, `comment_count`, `checked_at`
→ 영상 확인 코드를 실행하면 채워짐. URL을 추가할 때마다 다시 실행해도 됨

## 마지막에 채우는 칸

| 열 | 넣을 값 | 기준 |
|---|---|---|
| `use` | `Y` 또는 `N` | 확인 코드 실행 후 결정. 아래 기준을 모두 만족하면 Y |

## 영상 고르는 순서

1. **브랜드 공식 채널**의 광고 원본 (광고주 채널 또는 제작 대행사 채널)
2. 원본이 삭제됨 / 댓글 막힘 / 댓글 50개 미만이면 → 그 사례를 다룬 **뉴스 리포트 영상** (방송사·언론사 채널)
3. 공식 영상이 충분해도 뉴스 영상이 있으면 한 줄 더 추가해도 됨 (반응 비교용)

## use=Y 기준

- [ ] `video_exists` = Y
- [ ] `comments_enabled` = Y
- [ ] `comment_count` 50 이상 (답글 포함 숫자라 실제 수집량은 더 적음)
- [ ] 같은 광고가 맞음 (`published_at`이 cases.csv의 시기와 비슷함)
- [ ] 개인 유튜버, 리액션 채널, 광고 모음 채널, 무단 재업로드가 아님

## 함께 확인할 것 (note에 기록)

- **AI 사용 표기:** 제목·설명란·화면에 "AI로 제작" 등의 표기가 있는가 → cases.csv의 `disclosed` 근거
- **대행사 채널 여부**
- 10분 안에 못 찾으면 `video_url`을 비워 두고 note에 `영상 못 찾음`

## 개인정보 규칙

- 댓글 작성자 이름·채널 ID·프로필은 어디에도 적지 않음
- `channel` 열은 영상을 올린 채널(브랜드·방송사) 이름이라 괜찮음
