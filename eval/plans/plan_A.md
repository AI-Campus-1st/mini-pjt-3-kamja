# [더미 A] 루미에르 봄 신제품 SNS 캠페인 기획안

※ 심화(기획서 확인) 평가용 가상 기획서. 브랜드·제품은 실재하지 않음.

## 1. 개요
- 브랜드: 루미에르 (국내 색조 화장품 브랜드)
- 제품: 신제품 '데일리 글로우 쿠션' 3종
- 캠페인 기간: 2027년 3월 2일 ~ 3월 31일
- 채널: 인스타그램, 유튜브 쇼츠
- 목표: 20~30대 여성 대상 신제품 인지도 확보, 공식몰 유입 증대

## 2. 콘텐츠 방침
- AI를 활용한 콘텐츠는 게시글 본문 첫 줄에 'AI로 제작한 콘텐츠입니다' 문구를 넣어 게시하는 시점부터 밝힌다.

## 3. 콘텐츠 구성
1. 메인 피드 이미지: 쿠션 3종의 제품 단독 컷은 스튜디오 촬영 없이 이미지 생성 AI로 만든다.
2. 메이크업 시연 릴스: 메이크업 아티스트의 시연은 스튜디오에서 실제로 촬영하고, 뒤쪽 배경인 가상 쇼룸만 AI로 생성해 합성한다.
3. 사용법 콘텐츠: 쿠션 바르는 순서를 설명하는 30초 튜토리얼 숏폼은 장면 전체를 영상 생성 AI로 만든다.
4. 협업 게시물: 뷰티 인플루언서 3명이 제품을 직접 써 보는 사용 후기 영상을 실제로 촬영해 함께 올린다.

## 4. 일정
- 2월: 콘텐츠 제작, 인플루언서 섭외
- 3월 2일: 캠페인 시작, 주 2회 게시
- 3월 31일: 캠페인 종료, 성과 정리
