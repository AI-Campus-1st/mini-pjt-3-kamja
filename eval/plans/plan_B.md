# [더미 B] 온담식품 '불향 짬뽕라면' 출시 광고 기획안

※ 심화(기획서 확인) 평가용 가상 기획서. 브랜드·제품은 실재하지 않음.

## 1. 개요
- 브랜드: 온담식품 (국내 라면·간편식 제조사)
- 제품: 신제품 '불향 짬뽕라면'
- 목표: 출시 초기 인지도 확보, 대형마트 매대 판매 증대
- 채널: TV·유튜브 광고, 매장 디지털 사이니지, 자사몰

## 2. 제작 방침
- 광고 영상과 이미지에는 AI로 제작했다는 문구를 따로 넣지 않는다.

## 3. 제작물
1. 메인 광고: 15초 TV 광고 영상은 촬영 없이 영상 생성 AI로 처음부터 끝까지 만든다.
2. 매장 사이니지 영상: 실제 주방에서 라면을 끓이는 장면을 촬영하고, 그릇 위로 피어오르는 김·연기 효과만 AI로 생성해 덧입힌다.
3. 레시피 카드뉴스: 자사몰 레시피 카드뉴스에 나오는 셰프는 실제 요리사 대신 AI로 만든 가상 인물로 한다.
4. 현장 행사: 대형마트 시식 행사 홍보 사진은 행사 당일 현장에서 직접 촬영한 사진을 쓴다.

## 4. 예산 배분
- 메인 광고 50%, 매장 사이니지 20%, 자사몰 콘텐츠 15%, 현장 행사 15%
